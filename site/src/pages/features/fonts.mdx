# Fonts [Load and apply custom fonts]

Vocs uses Zyzz's default font stacks, with Geist loaded for body text. Add font files or package imports to `src/pages/_root.css` when you need a different family.

## Load Font Files

Place fonts in `public/fonts`, then define their families and apply them with ordinary CSS.

```css [src/pages/_root.css]
@font-face {
  font-family: 'My Sans';
  src: url('/fonts/my-sans.woff2') format('woff2');
  font-display: swap;
}

@font-face {
  font-family: 'My Mono';
  src: url('/fonts/my-mono.woff2') format('woff2');
  font-display: swap;
}

body {
  font-family: 'My Sans', sans-serif;
}

pre, code, kbd, samp {
  font-family: 'My Mono', monospace;
}
```

Vocs loads `_root.css` on every page. Unlayered CSS overrides the built-in layered global styles.

## Load Font Packages

Install your preferred font package, then import its CSS before other rules in `_root.css`.

```sh
npm install @fontsource/inter
```

```css [src/pages/_root.css]
@import '@fontsource/inter/400.css';
@import '@fontsource/inter/600.css';

body {
  font-family: 'Inter', sans-serif;
}
```

The old `--vocs-font-family` and `--vocs-font-family-mono` variables have been removed. Use CSS declarations for global overrides and `fontFamily` in [Zyzz styles](/features/zyzz) for custom components.
