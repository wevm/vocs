# Tailwind CSS [Add optional Tailwind utilities]

Vocs uses [Zyzz](/features/zyzz) for its built-in UI. To retain Tailwind utilities in your own pages, install and configure Tailwind separately.

```sh
npm install -D tailwindcss @tailwindcss/vite
```

Add the Tailwind plugin alongside Vocs in your existing Vite configuration.

```ts [vite.config.ts]
import tailwindcss from '@tailwindcss/vite'
import { defineConfig } from 'vite'
import { vocs } from 'vocs/vite'

export default defineConfig({
  plugins: [vocs(), tailwindcss()],
})
```

Import the theme and utilities in `src/pages/_root.css`. Vocs already supplies a reset, so omit Tailwind's Preflight.

```css [src/pages/_root.css]
@import 'tailwindcss/theme.css' layer(theme);
@import 'tailwindcss/utilities.css' layer(utilities);

@custom-variant dark (&:where([data-vocs-theme='dark'], [data-vocs-theme='dark'] *));
```

Use ordinary Tailwind classes in MDX or JSX. The old `vocs:` utilities and Vocs CSS theme tokens are no longer available.

```mdx
<div className="rounded-lg p-4 text-zinc-900 dark:text-zinc-100">
  Custom page content
</div>
```

See the [Tailwind Vite guide](https://tailwindcss.com/docs/installation/using-vite) for additional configuration.
