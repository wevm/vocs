# Theming [Use the default theme and configure site branding]

Vocs uses the [Zyzz default theme](/features/zyzz). Colors adapt to the active light or dark scheme. The same theme supplies fonts, spacing, radii, and component colors.

Configure the color scheme, logo, icon, and syntax highlighting in `vocs.config.ts`. The `accentColor` option and the old global design tokens are no longer supported.

### Choose A Color Scheme

`colorScheme` controls whether your site is fixed to one scheme or allows switching.

```ts [vocs.config.ts]
import { defineConfig } from 'vocs/config'

export default defineConfig({
  colorScheme: 'light dark'
})
```

Supported values:

- `'light'` locks the site to light mode
- `'dark'` locks the site to dark mode
- `'light dark'` follows the user's system preference and enables the built-in theme toggle

If you want users to switch between light and dark mode, use `'light dark'`.

### Set Logo And Icon

Use `logoUrl` for the brand mark shown in the UI and `iconUrl` for the favicon and related metadata. Both options accept either a single string or per-scheme assets.

```ts [vocs.config.ts]
import { defineConfig } from 'vocs/config'

export default defineConfig({
  logoUrl: {
    light: '/logo-light.svg',
    dark: '/logo-dark.svg'
  },
  iconUrl: '/icon.svg'
})
```

### Pick Code Block Themes

Syntax highlighting is configured separately from the rest of the UI theme. Use `codeHighlight.themes` to choose the Shiki theme for light and dark mode.

```ts [vocs.config.ts]
import { defineConfig } from 'vocs/config'

export default defineConfig({
  codeHighlight: {
    themes: {
      light: 'github-light',
      dark: 'github-dark-dimmed'
    }
  }
})
```

You can also add language aliases or other Shiki options in the same `codeHighlight` block. See also: [Code & Syntax Highlighting](/writing/syntax-highlighting).

## Layout Dimensions

Vocs retains layout-specific CSS variables for dimensions that are not design tokens. Override them in `src/pages/_root.css`.

```css [src/pages/_root.css]
:root {
  --vocs-layout-content: 760px;
  --vocs-layout-sidebar: 260px;
  --vocs-layout-outline: 220px;
}
```

Existing layout overrides named `--vocs-spacing-content`, `--vocs-spacing-sidebar`, or `--vocs-spacing-outline` now use the `--vocs-layout-` prefix. Banner height is measured automatically.

For custom components, use `style` and `theme.vars` from `zyzz/default`. For font loading and CSS overrides, see [Fonts](/features/fonts).
